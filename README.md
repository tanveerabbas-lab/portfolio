# Portfolio (plain HTML, CSS and JavaScript)

No build step, no npm, no libraries. Just open `index.html`.

| File | Purpose |
|---|---|
| `content.js` | **Edit this.** All text, links, projects, menu items and image paths (search for `TODO`) |
| `index.html` | Page shell, title and SEO description |
| `style.css` | All styling |
| `script.js` | Builds the page from `content.js` |
| `icons.js` | Icon drawings |
| `images/` | `hero.webp`, `profile.jpg` and the four project screenshots |

CV: put `cv.pdf` in this folder and set `cv: 'cv.pdf'` in `content.js`.

## Put it on GitHub Pages (free)
1. Create a public repository and upload ALL files from this folder (so `index.html` is at the top level).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
3. After 1–2 minutes your site is at `https://USERNAME.github.io/REPO/`.
